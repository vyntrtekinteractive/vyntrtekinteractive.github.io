1. App Data & Analytics Overview

We do not require user accounts or store personal identifiers such as name, email, or phone number.

  • Google Firebase: Gameplay analytics, crash reporting, and performance diagnostics.
  • Google AdMob: Advertising services using GAID (Advertising ID).

2. Data Deletion Request

To request deletion or inquiry of associated data:

Email: support@vyntrtek.com

Subject: Data Deletion Request – [Game Name]

Include:
1. Game name
2. Device model & OS version
3. Advertising ID (optional)

3. Device-Level Controls

You may reset or delete advertising identifiers directly:

1. Settings → Google → Ads → Reset Advertising ID
2. Settings → Apps → Game → Clear Data
